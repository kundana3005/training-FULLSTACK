Variables:
-------------
    ->Variables are the named memory location used to store data or values and it can change N no.of times during execution

Way to declare Variables:
---------------------------
    1. let
        -> let variable acts like a block scope.
        -> declaration and initialization in same line and different line is possible.
        -> re-declaration is not possible and re-initialization is possible.
        -> we cannot hoist the "let variables".
    2. var
        -> var variable acts like a global scope.
        -> declaration and initialization in same line and different line is possible.
        -> re-declaration  and re-initialization is possible.
        -> we can hoist the "var variables".
    3. const
        -> const variable acts like a block scope and final.
        -> declaration and initialization in same line is possible.
        -> declaration and initialization in  different line is not possible.
        -> re-declaration  and re-initialization is not possible.
        -> we cannot hoist the "const variables".

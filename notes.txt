2. unpaired Tags/self Closing tags:
------------------------------------
	-> Any tags having only opening tags
	Ex: <br> - Break the line,
	    <hr> - horizontal line,
            <input> - form,
	    <img> - display image

Attributes in html:
-------------------
-> Attributes are the additional information given to the tags
-> Attributes are always in opening tag (static tag)
-> Most of the Attributes are key and value pair

Ex: 
	<input  type="password" required placeholder="Enter Your Name">
	<p style="color: red" id="para-container" align="center">Content</p>

if two are with same name and different values then it will follow the first one 
ex:
	<p align="left" align="center" style="color: red" id="para-container">Content</p> --> follows left
	<p align="center" align="left" style="color: red" id="para-container">Content</p> --> follows center

HTML Elements
--------------
-> opening tag, closing tag and content together is called elements
Types:

1. Block Level Elements
     ->Any elements which will consumes entire width of the browser
	Ex: all Headings Tags, <div></div>, <p></p>, <li></li>, semantic tags ..etc
2. Inline Level Elements
     ->Any elements which will consumes only content width of the browser
	Ex: all Formatting tags, <span></span>, <input>, <img>, <a></a>

List In HTML:
-------------
	-> List Are used to display items in order(numberings) or unordered(symbolic) formate
	Types:
	------
	1.Orderd List
		->In HTML <ol> </ol> represent the order List
		-><ol> </ol> contains <li></li>(list items)
			shortcut - 
			a. ol>li*6

					<li></li>

					<li></li>
					<li></li>
